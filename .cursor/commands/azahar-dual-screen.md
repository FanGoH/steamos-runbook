# Azahar dual-screen

Put standalone Azahar in the desktop GameStream layout: 3DS top screen on HDMI-A-1, bottom touch screen on Virtual-sunshine-ds.

Follow `.cursor/skills/azahar-dual-screen/SKILL.md` and run `scripts/ensure-azahar-dual-screen.sh`. Game Mode `:48200` is **`checkpoint-2026-09-18-gamepad-xtest`** (`.cursor/skills/sunshine-ds-gamemode/SKILL.md`); do not run the KWin desktop script there.
