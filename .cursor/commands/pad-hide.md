# Pad Hide

Hide extra USB/BT pads from Steam/games without unplugging them (NMH3 / Moonlight).

Follow `.cursor/skills/pad-hide/SKILL.md` and run `python3 scripts/hide-controllers.py`. Decky UI: `scripts/ensure-pad-hide-decky.sh`. Reload name is **Pad Hide**. SSH sudoers: `scripts/ensure-hide-controllers.sh`.
